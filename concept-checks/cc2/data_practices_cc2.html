2.4 A.3: Descriptive Statistics (6 points)

Now let’s calculate specific statistics. The mean() and sd() functions calculate the mean and standard deviation.

Important: When data has missing values (NA), we need to tell R to ignore them using na.rm = TRUE. Otherwise, R will return NA as the answer.

Run this code to calculate statistics for flipper length:

# Calculate mean flipper length (na.rm = TRUE tells R to ignore missing values)
mean(penguins$flipper_length_mm, na.rm = TRUE)

# Calculate standard deviation of flipper length
sd(penguins$flipper_length_mm, na.rm = TRUE)

3.3 B.3: Boxplot (4 points)

Boxplots are great for comparing distributions across groups.

Run this code:

# Boxplot comparing body mass across species

  geom_boxplot(fill = "lightblue") +

    x = "Species",
    y = "Body Mass (g)"
  ) +
  theme_minimal()
Reading a Boxplot
  • The thick line in the middle is the median (middle value)
  • The box contains the middle 50% of the data
  • The whiskers extend to show most of the remaining data
  • Dots beyond the whiskers are potential outliers (unusual values)

  1. Copy this boxplot into your write-up. (1 point)

4.1 C.1: Code Comments (4 points)

Good code includes comments that explain what the code does and why. This helps others (and your future self!) understand your work.

Your task: Add comments to each line of the following code block. Write the commented version in your R script.

# Add a comment above EACH line explaining what it does
# Example: "# Remove rows where sex is missing"

penguins_clean <- penguins |>
  filter(!is.na(sex)) |>
  mutate(body_mass_kg = body_mass_g / 1000) |>
  select(species, island, body_mass_kg, sex)
Hints for Understanding This Code
  • filter() keeps only rows that meet a condition
  • !is.na(sex) means “sex is NOT missing”
  • mutate() creates new variables
  • select() chooses which variables to keep
  • The |> symbol (called a “pipe”) sends the result to the next line
